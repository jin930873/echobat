# 回声定位 · 夜蝠（Echo Bat）

一只只能靠声音看世界的蝙蝠。睁眼什么都看不见，发一声，四周才亮一下。

> 计算机动画与游戏开发 · 期末作品
> 开发者：金小琴　　版本：4.0.0

---

## 一、这是什么

横版俯视的 2D 觅食游戏。玩家操作一只夜行的蝙蝠，在完全黑暗的洞穴里靠回声定位找虫吃。

游戏里**没有任何常亮的光源**。屏幕大部分时间接近全黑，唯一的照明来自玩家主动发出的声波——声波以自身为圆心扩张，扫过的墙壁、石头、萤火虫会被短暂点亮，两三秒后重新沉回黑暗。所以“看清”不是免费的，每一次发波都要先想清楚：值不值得暴露自己。

全部美术与音效都由脚本在运行时程序化生成，工程内不含任何外部素材文件。

## 二、操作

| 操作 | 键位 |
|---|---|
| 飞行 | `WASD` 或 方向键 |
| 回声定位（照亮四周） | `空格` |
| 俯冲捕食 | 鼠标左键 |
| 重新开始本关 | `R` |
| 进入下一关 / 开始游戏 | 鼠标左键 |

建议用键盘 + 鼠标玩。手机浏览器可以打开，但没有触屏适配。

## 三、三关结构

| 关 | 关卡名 | 目标 | 威胁 |
|---|---|---|---|
| 1 | 洞口 | 熟悉回声，吃虫 | 无 |
| 2 | 深窟 | 30 秒内与另一只蝙蝠抢 30 只虫，吃得多者胜 | 同类竞争 |
| 3 | 洞底 | 凑够 110 分才能飞出去 | 盲螈：每发一次声波都会朝你的方向爬过来 |

三关是一条连贯的线：先学会看，再学会抢，最后学会怕。第三关把前两关教会你的动作反过来用了一次——你赖以生存的声波，正好是敌人唯一的线索。

## 五、怎么运行

**网页版（本目录）** 不能双击 `index.html` 打开——浏览器会拦截 `file://` 下的资源请求，页面会一直黑屏并报 `Failed to download ... .unityweb`。必须通过 http 服务访问：

```bash
# 在本目录下执行
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。

**Windows 版**：解压后双击 `EchoBat.exe`，需保留整个文件夹（`EchoBat_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 都在同级）。

## 六、注意事项

- 网页版首次点击后才会有声音，这是浏览器的音频自动播放策略，不是故障。
- 网页版的帧率受浏览器与显示器刷新率限制，60 只是上限，不保证稳定达到。
- 浏览器地址栏出现 `Not Secure` 或 http 提示属于正常，本地服务没有证书。
